# Projeto Criando uma Pokedex 

Este projeto foi desenvolvido durante o bootcamp da DIO e consiste em uma 
aplicação web responsiva que exibe uma lista de Pokémon, apresentando nome, 
imagem e atributos de cada personagem. A aplicação consome uma API externa 
para obter os dados em tempo real, garantindo informações atualizadas. 
Foi construída utilizando HTML, CSS e JavaScript, com foco em organização,
consumo de APIs e criação de interfaces interativas.
